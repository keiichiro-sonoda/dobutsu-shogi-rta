# 記録 #27 で分かったこと

**`Makefile` の `gcc` 行に `-fno-semantic-interposition` を1つ足した。** 変数はこれ1つで、`animal_shogi.c`・`.h`・`.py` は
#26 とバイト同一。

**完走 0:02:33 → 0:02:31（208.85× → 211.95×）。−2.25 秒（−1.5%）。**
内訳は全探索 71.40 → 69.05 秒（−2.34）、後退解析 82.45 → 82.55 秒（+0.09）。
`dat/` は #26 と全213ファイルでバイト一致した。

`-fPIC -shared` の既定では、同じ `.so` の中の関数どうしの呼び出しも「実行時に別の定義へ差し替えられうる」ものとして扱われ、
PLT を経由し、インライン展開もされない。このフラグは差し替えないと約束して、それをやめさせる。このリポジトリは `.so` を
ctypes から呼ぶだけで、関数を差し替える仕組みは使っていない。

| 呼び出し元 | #26 | #27 |
|---|---|---|
| `nextBoardInvNormal`（生成器） | `normalBoard@plt` 3、`invBoard@plt` 1 | `normalBoard` は **0（インライン展開）**、`invBoard` 1（直接） |
| `nextBoardSeenNormal`・`nextBoardIndexNormal` → `nextBoardInvNormal` | PLT 経由 | 直接 |
| `expandRound` → `nextBoardSeenNormal`、`buildSuccRange` → `nextBoardIndexNormal` | PLT 経由 | 直接 |
| `.so` 全体 | PLT 経由 60 / 直接 0 | PLT 経由 43 / 直接 13 |

`objdump -d` の数え方は門番の [`calls.py`](../../experiments/gate_27_no_interposition/calls.py)、門番の本が作った `.so` での表は
[`calls.txt`](../../experiments/gate_27_no_interposition/logs/calls.txt)。PLT が小さくなって `.text` が前へ動き、インライン展開した
関数が大きくなるので、全部の関数の番地が −112〜−336 バイト動いた（[`symbols.txt`](../../experiments/gate_27_no_interposition/logs/symbols.txt)）。

`tests/test_impl_27_no_interposition.py` が、`Makefile` の差がこのフラグ1つだけであることと、2腕をそれぞれの `Makefile` で
ビルドしたときの呼び出しの変化と、その `.so` で打ち切って回した成果物が #26 とバイト一致することを固定している。
⚠️ 等価性検査と `conftest` の `.so` は自前の gcc 行でビルドするので `Makefile` を通らない（#18 と同じ事情）。このテストの中だけ、
`Makefile` で作った `.so` に差し替えている。

### 1回の呼び出しあたり — P2 では F1 の半分以下

`normalBoard()` は生成した後続ごとに呼ばれる。F1 で約12〜13億回、P2 でも辺の本数（938,671,869）以上。

| | 門番の差（ユーザー時間） | `normalBoard()` の回数 | 1回あたり |
|---|---|---|---|
| F1 | −2.53 秒 | 約12〜13億 | 約 2.0 ns |
| P2 | −0.89 秒 | 約 9.4 億以上 | 1 ns 以下 |

どちらも、ほかの呼び出しが PLT を通らなくなったぶんと置き場所の効果を含めて、`normalBoard()` の回数で割っただけの値。
P2 の生成器は後続ごとに索引を引く（`nextBoardIndexNormal()`。DRAM の待ちが長い）ので、呼び出しの手間がその待ちに F1 より
多く隠れていたと読めるが、測っていない（性能カウンタは取っていない）。#26 の門番でも、P2 は生成器の差の 83% が出ていて、
「P2 のほうが隠れやすい」ことを示す材料にはならない（#26 は分岐の読み違いを消す変更で、今回は呼び出しの手間を消す変更）。

#18 のコード（F1 約 98 秒）での F1 −3.75 / −3.92 秒（壁時計）に対して、今回は −2.54 秒。コードも本数も並べ方も違うので、
差どうしを引き算して偏りを出すことはしない。
