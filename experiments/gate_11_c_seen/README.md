### F1 の増分は 28.56 秒しかなかった

⚠️ **予測は +100〜+300 秒。大きく外した**（C の探査を 0.15〜0.25 µs/回と置いていた）。

「C の探査の実費」と「Python のオブジェクト生成が減ったぶん」が相殺している（**推定**）。
